# Set up /jobs

Read [the jobs skill](skills/jobs/SKILL.md), then use [the complete setup example](skills/jobs/examples/setup.md). Read the resume, propose profile and target companies in chat, and save the person's rulings once. Questions is available without gating setup.

Prepare a separate owned workspace. The Mac or Linux host runs the server and website; the core iPhone build and deploy-when-away path requires a Mac, Xcode, the person's Apple signing and paired device. Setup stages inactive services. Run `tools/career.py check` to diagnose what needs fixing; `--offline` leaves sign-in and scanner reachability explicitly unverified. See [the reference](skills/jobs/reference.md) for contracts and deployment.
