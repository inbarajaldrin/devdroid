---
name: apple-docs
description: Fetch Apple's current developer documentation live instead of answering from memory. Use whenever the user builds for iPhone, iPad, Mac, Apple Watch, Apple TV, Apple Vision Pro or CarPlay (iOS, iPadOS, macOS, watchOS, tvOS, visionOS, Mac Catalyst); writes or debugs Swift, SwiftUI, UIKit, AppKit, RealityKit, WidgetKit or any other Apple framework; checks API availability, deprecations or release notes; designs with the Human Interface Guidelines; asks about App Review, WWDC sessions, Swift language features or Swift Evolution proposals; converts a Chrome or Firefox extension to Safari; or packages, signs and notarizes a Mac app from SwiftPM. Use it for ordinary questions such as "how do I share state between SwiftUI views?" or "will App Review allow this?", even when the user does not ask for documentation.
---

Apple's APIs change every year, and a model's memory of them is already old. Fetch the current page before any claim that depends on a signature, an availability, a deprecation or a guideline; check availability against the user's platforms and deployment target, and say when a page describes a beta.

Append `.md` to a `developer.apple.com` documentation, design-guidelines or release-notes URL, after removing any fragment, query or trailing slash: `https://developer.apple.com/documentation/swiftui` becomes `https://developer.apple.com/documentation/swiftui.md`. Start at a hub in [catalog.md](catalog.md) and follow its links down rather than guessing deep paths; the catalog also says how to read the sources that work differently (HTML for the App Review Guidelines, WWDC, the forums and news; JSON for the technology index, the Swift book and Swift Evolution). When a markdown page is missing or only a stub, the same page is served as JSON at `https://developer.apple.com/tutorials/data<path>.json`.

Some agents' fetch tools refuse `text/markdown` or JSON responses; fetch those with curl and a browser user agent instead (`curl -fLsS -A 'Mozilla/5.0' '<url>'`). A fetch counts only when it returns the topic's actual content, not a title, a redirect choice or a page asking for JavaScript. If nothing can be fetched, say what could not be verified instead of answering from memory.

Cite the page's normal URL, without `.md` or `/tutorials/data`. A WWDC session reflects the year it was recorded, and a forum post is one developer's report: confirm current behaviour in the reference documentation.

Two local guides cover what Apple's docs do not. [guides/safari-extensions/_index.md](guides/safari-extensions/_index.md) routes building a Safari Web Extension from a Chrome or Firefox one: the converter's bundle-identifier trap, the APIs Safari lacks and how to deliver files without them. [guides/mac-app-from-swiftpm.md](guides/mac-app-from-swiftpm.md) turns a SwiftPM executable into a signed, notarized app, with the helpers in [scripts/](scripts/); read a script before running it in the user's project. [tests/README.md](tests/README.md) explains how to re-verify this skill.
